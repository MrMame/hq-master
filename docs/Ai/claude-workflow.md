# Claude Workflow

## Der "Workflow-Trick" im Chat: Häufiger /clear nutzen
Da deine 126k Token hauptsächlich durch den langen Gesprächsverlauf zustande kamen, solltest du dir folgende Routine angewöhnen:
- Wenn ein Feature fertig gebaut ist und fehlerfrei läuft, tippe einfach **/clear** in den Chat.
- Dein Code ist ja nun sicher auf der Festplatte gespeichert. Durch /clear vergisst Claude das "Geplänkel" der letzten Stunden, liest deinen frischen Code einmal kurz ein und du startest das nächste Feature mit einem winzigen, supergünstigen Cache.
