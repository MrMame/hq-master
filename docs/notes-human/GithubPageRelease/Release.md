To Release directly to github-pages angular-cli-ghpages is used.


Use the following command to release to github pages 
```bash
ng deploy --base-href="https://mrmame.github.io/hq-master/"
```

The angular page will be build into dist/hq-master folder. 
Then it will be pushed to the branch gh-pages. This Branch will be 
used for gihub pages.
You can open the page by using the following url : "https://mrmame.github.io/hq-master/"
