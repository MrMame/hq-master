Was passiert im Hintergrund?

cdkDrag — markiert ein Element als ziehbar. Ohne cdkDropList kann es frei im Browser bewegt werden.

cdkDropList — definiert eine Zone. Elemente können nur zwischen verbundenen Zonen transferiert werden.

[cdkDropListConnectedTo] — Array von Zonen-IDs, zwischen denen Transfers erlaubt sind.

cdkDragPlaceholder — das HTML am Ursprungsort während des Drags (ersetzt das unsichtbare Original).

cdkDragPreview — das HTML, das dem Cursor folgt.

(cdkDropListDropped) — das Event enthält: welches Element, von wo, nach wo.
