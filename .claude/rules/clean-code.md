# Coding Standards & Clean Code

## File Length
- **Constraint:** Code files MUST NOT exceed 150 lines of code.
- If a file grows larger, refactor and split it into smaller, reusable modules or components.

## Clean Code Principles
- Apply SOLID principles.
- Use meaningful, self-explanatory variable and function names.
- Keep functions short and focused on a single responsibility (Single Responsibility Principle).
- Prefer clarity over cleverness. Write readable code.
